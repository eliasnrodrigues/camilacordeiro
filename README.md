# Camila Cordeiro | Arquitetura

Site estático de apresentação, feito em HTML, CSS e JavaScript sem dependências externas de compilação. A identidade visual inclui um símbolo original de coruja em SVG.

## Publicar com GitHub Pages

1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**, depois salve.
4. Aguarde a publicação. O endereço ficará no formato `https://eliasnrodrigues.github.io/camilacordeiro/`.

## Antes de divulgar

- Troque `contato@exemplo.com.br` pelo e-mail profissional da Camila no `index.html`.
- As fotos estão identificadas no site como referências visuais, não como projetos executados pela arquiteta.
- Atualize áreas de atuação, fotos e informações de contato conforme os serviços reais.

## Arquivos

- `index.html`: site completo e responsivo.
- `assets/owl-mark.svg`: logo vetorial da coruja.
- `favicon.svg`: ícone do site.

Abra `index.html` localmente para visualizar sem instalação.
